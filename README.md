# Mini C Compiler

This is a small C-like compiler that I built from scratch using C.

I made this project to understand how a compiler actually works — from taking source code as input to generating assembly code.

## What it can do

- Read C-like code from a `.c` file
- Break the code into tokens using a Lexer
- Parse the tokens and create an AST
- Handle variables
- Handle variable assignment
- Handle arithmetic operations
- Handle comparison operators
- Handle `if` / `else`
- Handle `while` loops
- Generate x86-64 assembly code
- Show basic errors with line numbers
